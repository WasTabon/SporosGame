# SporosGame — Iteration 7 FIX (level solver + auto-balance)

## Что починено
L4 был нерешаем (2 базовые споры физически не могут покрыть 11 клеток после исключения Block). Балансировка предыдущей итерации делалась без верификации.

## Решение
Добавлен brute-force solver editor скрипт который:
1. Берёт каждый LevelData
2. Перебирает комбинации (cells choose k) с возрастающим k
3. Для каждой комбинации перебирает назначение типов спор (Basic/Diagonal)
4. Симулирует физику: placement → 4 луча в направлениях типа → активация клеток с учётом Block/Limited
5. Если найдено решение — записывает min spores + 1 как inventory count

Если уровень слишком большой для brute-force (>5M комбинаций) — применяется эвристика: `playable_cells / max(w,h) + 1`.

Layout клеток (Block/Fixed/Limited позиции) не меняется — solver балансирует только spore count.

## Файл
- `Assets/SporosGame/Editor/Iteration07_LevelSolver.cs` (новый, дополнительный editor)

## Что сделать
1. Распаковать (добавит 1 файл)
2. Дождаться компиляции
3. `Tools → SporosGame → Iteration 7 → Auto-Solve and Balance Levels`
4. Прогресс-бар покажет какой уровень обрабатывается. Для крупных уровней (7x7) может занять до минуты
5. Console → отчёт по каждому уровню (`L4: minSolve=3 (basic 3, diag 0), given=4`)
6. Play — все уровни решаемы

## Ограничения
- Solver не перебирает порядок placement (для уровней с Limited некоторые сложные решения могут быть пропущены, но базовое решение гарантировано если оно существует)
- Для уровней >5M комбо используется heuristic — может дать больше спор чем нужно
- Layout не меняется — если хочешь чтобы уровень был сложнее, добавь Block клеток в LevelData inspector и перезапусти solver

## Можно запускать многократно
Solver перезаписывает spore counts каждый раз. После ручных правок layout можно запускать снова.
